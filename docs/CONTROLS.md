# Controls

The default bindings cover keyboard + mouse, and every action is remappable in
**Settings → Controls**. Gamepad and touch are supported where the browser
allows (see Limitations).

## Movement

| Input | Action |
| --- | --- |
| `W A S D` | Move |
| `Shift` | Sprint |
| `Space` | Jump / swim up |
| `Ctrl` (hold) | Crouch |
| Mouse | Look (pointer lock; click the canvas to capture) |
| Mouse wheel | Dolly third-person camera / rotate buildings in build mode |
| `Mouse 2` | Orbit camera (drag) |

## Camera & view

| Input | Action |
| --- | --- |
| `C` | Cycle camera: third person → first person → free-fly → city overview |
| `V` | (free-fly) descend |
| `Tab` | Open fullscreen map (also `M`) |
| `M` | World map |
| `N` | World statistics panel |
| `F3` | Debug overlay (FPS, position, chunk counts, weather, sim detail) |
| `Esc` | Pause menu / close current panel |

## Tools (press `B` for the tool menu, or the hotbar)

| Input | Action |
| --- | --- |
| `B` | Tool / build menu |
| `E` | Interact (inspect villagers, animals, buildings; apply tool) |
| `R` | Rotate building ghost (or mouse wheel while building) |
| `1–8` hotbar | Raise, lower, smooth, flatten, plant tree, remove vegetation, build house, inspect |
| `0–4` | Time speed: pause, 1×, 4×, 16×, 64× |
| `Ctrl+Z` | Undo terrain stroke |
| `G` | God tools (seed, weather, season, time, water, fire, rain, animals, population) |
| `F` | Follow the selected villager for a day |

## Survival (can be disabled in settings)

Health, stamina, hunger, thirst and warmth are shown as HUD bars. Eat and
drink near your settlement; cold weather and night drain warmth near water.

## Gamepad

Standard mappings apply: left stick move, right stick look, south button jump,
east interact, triggers for sprint/crouch, shoulders to cycle camera, start for
the pause menu.

## Touch

On-screen buttons for move/look/jump/sprint/interact/tool appear automatically
on touch devices; two-finger drag looks around, pinch zooms the camera.

## Interaction prompts

The HUD prompt area always shows the context action (`E` to talk, `E` to
inspect, tool name + radius while sculpting) so controls are discoverable
without the manual.
